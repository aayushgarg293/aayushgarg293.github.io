# play.aayushgarg.in

Aayush's playground: a page of tiles linking to small browser games. Plain HTML, no build step.

This is the account's main GitHub Pages site (repo `aayushgarg293.github.io`,
custom domain `play.aayushgarg.in`, from the `CNAME` file). Each game lives in
its own repo with GitHub Pages on, and GitHub serves it here by itself:
- play.aayushgarg.in/saturday-5-baje/
- play.aayushgarg.in/you-are-the-loading-bar/
- play.aayushgarg.in/hold-the-line-india/

## Add a game
1. Publish the game from its own repo with GitHub Pages.
2. Save a 640×360 screenshot to `img/`.
3. Copy a tile in `index.html`, change the link, image and text, and move the NEW tag to it.
4. If it's a highlight, add a card to the Mission log on aayushgarg.in too.

`_template/` is a starting shell for a small game that lives inside this repo instead (back link, title, stage, and a "How it works" section).
